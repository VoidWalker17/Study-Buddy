# Week 4 Journal — Study Buddy

## Class Diagram & Project Report

Week 4 focused on identifying the main classes required for Study Buddy and compiling the work completed so far into the project report.

---

## Class Diagram

The Class Diagram was prepared to represent the main entities and their relationships within the Study Buddy system.

The major classes identified include:

- User
- Study Resource
- Teacher Agent
- Child Agent
- Memory
- Test
- Question
- Answer
- Evaluation
- Dashboard

Each class was assigned responsibilities based on its role within the system.

For example, the User interacts with the application, Study Resources contain the uploaded learning material, and the Memory component stores the knowledge learned by the Child Agent.

---

## Class Relationships

The relationships between the different classes were also identified.

A User can upload multiple Study Resources and participate in multiple teaching sessions.

The Teacher Agent processes the Study Resources and generates Tests.

The Child Agent receives information from the teaching session and stores it through the Memory component.

The Test contains Questions and receives Answers, which are processed during Evaluation.

The final results are then made available through the Dashboard.
