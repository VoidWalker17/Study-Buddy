# Week 4 Journal — Study Buddy

## Prototype Development & Swimlane Diagram

Week 4 focused on preparing the initial prototype of Study Buddy and creating the Swimlane Diagram to represent the responsibilities of the different parts of the system.

---

## Prototype Development

The main task this week was preparing the initial prototype of Study Buddy.

The prototype was planned around the main workflow of the system and included the important screens required for the student to interact with the application.

The main screens included:

- Login / Signup
- Study Material Upload
- Dashboard
- Teaching Interface
- Test Interface
- Results and Evaluation

The prototype helped us visualize how the user would move through the system from uploading study material to viewing the final evaluation results.

---

## User Flow

The prototype follows the main Study Buddy workflow:

**Login → Upload Resources → Cold Baseline → Teaching Session → Memory Building → Test → Evaluation → Dashboard**

The screens were connected according to this workflow so that the overall user experience remains simple and easy to understand.

The prototype also helped us identify how the UI/UX work completed in the previous weeks could be represented in an actual application flow.

---

## Swimlane Diagram

The Swimlane Diagram was prepared to show how responsibilities are divided between the different participants in the Study Buddy system.

The main participants identified were:

- Student/User
- Study Buddy System
- Teacher Agent
- Child Agent
- Memory & Learning Engine

The diagram shows how the student interacts with the system and how information moves between the different agents and components.

---

## Process Responsibilities

The Student is responsible for uploading resources and teaching the Child Agent.

The Teacher Agent processes the study material, generates tests, and evaluates the results.

The Child Agent learns from the student's teaching and uses its stored memory during testing.

The Memory & Learning Engine processes the teaching information and updates the Child Agent's knowledge.

---

## Challenges

The main challenges were:

- Clearly dividing responsibilities in the Swimlane Diagram.
- Keeping the overall process easy to understand.
