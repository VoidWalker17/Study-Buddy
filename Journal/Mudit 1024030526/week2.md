# Week 2 Journal 

## Use Case Diagram & System Interactions

Week 2 focused on identifying the main interactions between the student and Study Buddy and representing them using the Use Case Diagram.

---

## Use Case Identification

The main actor identified for the system is the **Student/User**.

The major interactions identified were:

- Sign Up / Login
- Upload Study Material
- Take Cold Baseline Test
- Teach Child Agent
- Teach via Text
- Teach via Voice
- Update Child Agent Memory
- Generate Test
- Take Test
- Evaluate Answers
- View Dashboard

These use cases represent the main activities that a student can perform while using Study Buddy.

---

## Use Case Relationships

We also looked at how the different use cases are connected.

For example, the student teaches the Child Agent using text or voice. The teaching session is then used to update the Child Agent's memory.

After this, the Teacher Agent generates a test and evaluates the Child Agent's answers.

This helped us understand the relationship between the different parts of the system.

## Challenges

The main challenges were:
