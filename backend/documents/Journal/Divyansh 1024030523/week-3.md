# Week 3 Journal — Study Buddy

## UI/UX Completion & Data Flow Diagram Level 0

Week 3 focused on completing the initial UI/UX design of Study Buddy and preparing the Level 0 Data Flow Diagram to represent the system at a high level.

---

## UI/UX Design Completion

The main UI/UX work from the previous week was further refined and completed.

The main screens considered for the Study Buddy system include:

- Login / Signup
- Study Material Upload
- Dashboard
- Teaching Interface
- Test Interface
- Results / Evaluation

The navigation between these screens was also refined to make the overall learning process easier for the student to follow.

The main focus was to ensure that the UI matches the workflow of the system, starting from uploading study material and ending with viewing the final evaluation results.

---

## Data Flow Diagram Level 0

The Level 0 Data Flow Diagram was prepared to provide a high-level view of the Study Buddy system.

At this level, the entire application is represented as a single system, showing how the main external entity interacts with Study Buddy.

The main interaction involves the student providing information such as:

- Login details
- Study materials
- Teaching input

The system processes this information and provides outputs such as:

- Test questions
- Evaluation results
- Learning progress
- Dashboard information

This diagram helped us understand the overall flow of information between the student and the Study Buddy system.
