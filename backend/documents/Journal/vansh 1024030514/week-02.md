# Week 2 Journal — Study Buddy

## UI/UX Design

Week 2 focused on planning the user interface and overall user experience of Study Buddy.

The main goal was to understand how a student will move through the system and how the important features can be presented in a simple and user-friendly way.

---

## Main Screens

The initial UI/UX planning focused on the main screens required for Study Buddy:

- Login / Signup
- Study Material Upload
- Dashboard
- Teaching Interface
- Test Interface
- Results / Evaluation

The teaching interface was given more attention because it is the main interaction between the student and the Child Agent.

---

## Teaching Interface

The teaching interface will allow the student to explain a topic to the Child Agent.

We considered two possible teaching methods:

- **Text-based teaching**
- **Voice-based teaching**

The initial version will mainly focus on text-based teaching, while voice interaction can be developed in a later stage.

---

## Dashboard

The dashboard was planned to show the student's results after completing a learning session.

Some of the information that can be displayed includes:

- Baseline score.
- Final test score.
- Teaching effectiveness.
- Learning progress.

The main focus was to keep the dashboard simple so that students can understand their results easily.

---

## Challenges

The main challenges were:

- Keeping the interface simple and easy to use.
- Deciding what information should be shown on each screen.
- Designing the teaching interface around the project workflow.
- Making sure the UI can support future voice interaction.
